# Responsive Real Estate Landing Page

A fully responsive real estate landing page built from scratch using HTML and CSS.  
This project focuses on creating a clean UI and ensuring smooth responsiveness across all screen sizes.

---

##  Features

-  Fully Responsive (Mobile, Tablet, Desktop)
-  Clean and Modern UI Design
-  Optimized Layout and Structure
-  Minimal use of animations for better performance
-  Structured sections like Hero, Services, Projects, and Stats

---

##  Tech Stack

- HTML5  
- CSS3  

---

## 💡 About the Project

This project was built as part of my learning journey in frontend development.  
The design is inspired by an existing layout, but the implementation was done from scratch to practice responsiveness and layout structuring.

---

## What I Learned

- How to make layouts responsive using CSS  
- Importance of flexible units and media queries  
- Structuring sections for real-world landing pages  
- Writing cleaner and more maintainable CSS
